Installation

Follow the steps below to set up and run the Exsit – Next.js + Tailwind CSS project on your local machine.

1. Prerequisites

Make sure you have the following installed on your system:

  • Node.js (version 18 or higher)
  • npm or yarn (package manager)

2. Installation Steps

  • Download the Project Files
    Download the project ZIP file from your ThemeForest account and extract it to your desired location.
  • Navigate to the Project Folder
    Open your terminal and move into the project directory: 
    
cd exsit-next
  • Install Dependencies
    Run the following command to install all required packages: 
    
npm install
    or if you use Yarn: 
    
yarn install
  • Start the Development Server
    Once installation is complete, start the local development server: 
    
npm run dev

3. Build for Production

To create an optimized production build, run: 


npm run build

After building, start the production server with: 


npm start

That’s it! Your Exsit – Next.js + Tailwind CSS project is now ready to use. You can start customizing components and pages as needed.

Make sure your Node.js version is 18 or higher to ensure compatibility with Next.js 15 and Tailwind CSS 4.

Create new page

This guide walks you through the steps to create a new page in the template. By leveraging Next.js file-system routing and the extended routing configuration, you can easily add new pages with tailored settings.

Navigate to the app directory

In the src/app folder, decide where your new page should go. For example, if the page requires authentication, place it in the src/app/(protected-pages) directory. If it doesn’t require authentication, use the src/app/(public-pages) directory instead.

2. Create a New Folder and Page File

Inside the appropriate directory, create a new folder for your page and add a page.tsx file inside it. For example, to create a page called About: 


src/
 └── app/
     └── (public-pages)/
         └── about/
             └── page.tsx

3. Add Page Content

Open your newly created page.tsx file and add the following code: 


export default function AboutPage() {
  return (
    <section className="py-20">
      <div className="container mx-auto px-4 text-center">
        <h1 className="text-4xl font-bold text-gray-900 mb-4">
          About Exsit
        </h1>
        <p className="text-gray-600 max-w-2xl mx-auto">
          This is an example of how to create a new page in your Exsit Next.js project.
        </p>
      </div>
    </section>
  );
}

4. Run the Development Server

After saving your file, start your development server and navigate to the new page in your browser: 


npm run dev

Then open your browser and visit: http://localhost:3000/about

5. Optional: Add to Navigation

To make your new page accessible from the site menu, open your header or navigation component (usually found in src/components/) and add a new link pointing to /about.

Dark Mode

Exsit includes a built-in Dark Mode feature using Tailwind CSS and React state management. It allows users to switch between light and dark themes easily.

1. Dark Mode Toggle Component

The dark mode switcher is located in src/components/DarkToggle.tsx. It uses useState and useEffect hooks to remember the user’s theme preference. 


'use client';

import { useState, useEffect } from 'react';
import { Sun, Moon } from 'react-feather';

const DarkToggle = () => {
  const [darkMode, setDarkMode] = useState(false);

  useEffect(() => {
    if (typeof window !== 'undefined') {
      const savedTheme = localStorage.getItem('theme');
      const isDark =
        savedTheme === 'dark' ||
        (!savedTheme && window.matchMedia('(prefers-color-scheme: dark)').matches);

      setDarkMode(isDark);
      document.body.classList.toggle('dark', isDark);
    }
  }, []);

  const toggleDarkMode = () => {
    const newMode = !darkMode;
    setDarkMode(newMode);
    document.body.classList.toggle('dark', newMode);
    localStorage.setItem('theme', newMode ? 'dark' : 'light');
  };

  return (
    <button
      onClick={toggleDarkMode}
      className="flex items-center gap-2 cursor-pointer bg-gray-100 rounded-full px-4 py-2 text-sm font-medium transition-colors duration-200 text-gray-800 dark:text-gray-100 dark:bg-gray-800"
    >
      <div className={`flex items-center gap-2 ${darkMode ? 'hidden' : 'flex'}`}>
        <Moon size={22} />
        <span>Dark</span>
      </div>

      <div className={`flex items-center gap-2 ${darkMode ? 'flex' : 'hidden'}`}>
        <Sun size={22} />
        <span>Light</span>
      </div>
    </button>
  );
};

export default DarkToggle;

2. Tailwind Configuration

Tailwind CSS automatically supports dark mode via the dark class. The toggle adds or removes this class from the <body> element.

You can now use Tailwind’s dark mode utilities anywhere: 


<div className="bg-white text-gray-800 dark:bg-gray-900 dark:text-gray-100">
  <h1>Dark Mode Example</h1>
  <p>This text color changes based on the selected theme.</p>
</div>

3. Adding to the Header

To make the dark mode toggle accessible across the site, import it inside your main navigation or header component: 


import DarkToggle from '@/components/DarkToggle';

export default function Header() {
  return (
    <header className="flex justify-between items-center py-4">
      <h1 className="text-xl font-bold">Exsit</h1>
      <DarkToggle />
    </header>
  );
}

4. Customizing Styles

Modify the toggle appearance or colors by editing its Tailwind classes in src/components/DarkToggle.tsx. You can also replace icons or labels as needed.

5. How It Works

  • Automatically detects system dark mode preference on first load.
  • Stores user preference in localStorage.
  • Applies the dark class to the <body> for Tailwind compatibility.
  • Works instantly without requiring page reload.

Customization Guide

Exsit – Software, SaaS & Startup Next.js + Tailwind CSS Template is built to be fully customizable and developer-friendly. All files are well-organized, and you can easily modify layout, styles, and components to match your project’s needs.

1. Global Styles

The main global stylesheet is located at: 


src/app/globals.css

This file includes Tailwind base styles, custom utilities, and global overrides. You can add your custom CSS or extend Tailwind classes directly here.

2. Tailwind Configuration

Tailwind CSS is configured inside the following file: 


tsconfig.json

You can customize colors, fonts, spacing, breakpoints, and more by modifying the theme settings. Example:

3. Layout and Components

The main layout and UI components are located inside:

  • src/components/layout/ – Header, footer, and page layout components.
  • src/components/ui/ – Buttons, cards, and reusable UI elements.

You can edit these components or create new ones to match your project requirements.

4. Adding or Editing Pages

Each home page and inner page is located inside: 


src/app/

For example:

  • src/app/home-1/ – Home Page 1
  • src/app/home-2/ – Home Page 2
  • src/app/[...slug]/ – Dynamic routes for custom pages

To create a new page, simply duplicate an existing folder, rename it, and update its content and components.

5. Fonts and Styling

Font definitions are stored in: 


src/styles/_fonts.scss

You can update or replace font families and import additional Google Fonts here.

6. Configuration Files

  • next.config.ts – Main Next.js configuration file.
  • postcss.config.mjs – PostCSS settings used with Tailwind.
  • eslint.config.mjs – Linting rules for code quality.

Modify these only if you are familiar with Next.js and Tailwind configuration.

Note: Always run npm run dev after making configuration or style changes to see your updates reflected in real-time.
