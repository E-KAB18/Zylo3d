# Zylo3D — Digital Dentistry Manufacturing Platform

Next.js 15 marketing site for Zylo3D.

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` and fill in:

```env
NEXT_PUBLIC_SITE_URL=https://zylo3d.com
NEXT_PUBLIC_STRIPE_BUY_URL=https://buy.stripe.com/...
NEXT_PUBLIC_KOL_TESTIMONIAL_VIDEO_ID=   # YouTube video ID for ZyloDent page
RESEND_API_KEY=re_...
CONTACT_EMAIL=sales@zylo3d.com
```

## Stack

Next.js 15 · React 19 · Tailwind CSS v4 · TypeScript · Resend · Vercel
